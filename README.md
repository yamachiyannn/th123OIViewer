天則：対戦情報ビューワー　～th123OpponentInfoViewer

v0.1.1

東方非想天則の対戦中/観戦中に、きっと相手の情報を表示することを目的としたツールです

天則観のDBファイルを読み取ります


----------

①主な機能

・対戦相手情報のリアルタイム表示
・プロファイル検索
・天則観が起動していない/記録ができていないときの警告
・IP:Port入力欄

----------

②リアルタイム表示

対戦（キャラクターセレクトの状態）または観戦を検知すると、相手のプロファイルとDBファイルを照合して情報を自動表示します

対戦中は過去100戦の勝率や、前回対戦（その日を除く最後の対戦）の日時など
観戦中は勝率を並べて表示します

後述の天則観未起動時の警告機能などがあるため、対戦前はフルスクリーン状態を解除しておくことをおすすめします

対戦終了後も最後に対戦した相手のプロファイル名だけ表示されます

----------

③プレイヤー検索の使い方

あんまり使わないかも？

表示欄を右クリックすると出てくるメニューから開けます
（メニューからはフォントサイズも変えられます...デフォルト: 10 pxです プレイヤー検索ウィンドウでもフォントも変更できます）
プロファイルごとの情報を閲覧できます

入力欄に文字を入力してEnterを押すと、検索（部分一致）ができます
後述するプレイヤーとプロファイルどちらにも引っ掛かります

左上側のリストには未選択かつ検索条件に該当するもの、左下側のリストには選択済みのものが表示されます

プレイヤー管理では、一つ以上のプロファイルをまとめてプレイヤーとして登録できます
プレイヤー検索で、登録したプロファイルの代わりにプレイヤー名が表示されます
分かりづらい名前の表記を変えるのにも使えるかも
CombinedPlayers.dbに記録されます
まずはプロファイル一覧のところをクリックして始めてください

リバサルミネスカウンターは、設定したキーに反応して、押した日時と対戦相手（観戦でもできます）を記録します
RLcounter.txtにも履歴が残ります
10先でリバサルミネスが決まった回数を見る以外にも、対戦していてクリップに残したいと思った場面を書き残しておくのにも使えるかも？
重いと若干不安定になるかもしれませんので、その点ご留意ください

----------

④以下の場合に警告を表示します（背景色も派手なものに変わります）

1.天則観の起動が確認できない場合
2.対戦終了時に対戦記録の件数が増えていない（＝正常に記録できていない）場合

2の場合は、対戦中も認識できるよう警告音も鳴らします。しばらくの間背景が記録漏れをお知らせします

escで対戦を終了したとき、2.の場合と同じ挙動になってしまうため、その時は出てくるescボタンを押して警告を止めてください

----------

⑤以下の機能は右クリックメニューからオンオフを切り替えることができます
asobby.exeの起動確認
IP:Port入力欄
④の2.の場合の警告
オーバーレイ

IP入力欄では、IP:Portを入力してEnterでクリップボードにコピーします（手入力の人用←自分）
対戦/観戦を検知すると入力が消去されます

escを押す度に毎回ボタンを押すのが億劫に感じる方は、警告をオフにすることをおすすめします
天則観の起動が確認できない場合の警告は、設定を変更しても引き続き表示されます

キャラクターセレクト時および観戦時に、フルスクリーンでも情報を見ることができるようオーバーレイ表示をオンにできます

----------

⑥iniファイル

DBファイルの名前、デフォルトのフォントサイズ（2種）、⑤の機能のデフォルトのオンオフが設定できます

----------

⑦動作環境

Windows 11（多分10でもいけるはずですが未確認）
.NET Framework 4.7.2

----------

⑧フォルダ

展開したら、フォルダごと天則観（Default.db）と同じ場所に置いてください
天則観報告ツールと同じ感じです（適当）

----------
